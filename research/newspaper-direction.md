# Newspaper-Style Direction

Last updated: 2026-04-21

## What Makes The Niccolo Miranda Style Work

- Editorial hierarchy:
  - Loud masthead, aggressive display typography, dense subheads
- Physical print feeling:
  - Paper texture palette, imperfect lines, framed blocks, visible rules
- Motion personality:
  - Marquee, horizontal drags, tactile transitions, reveal choreography
- Story-led layout:
  - Projects presented as "features," not cards
- Strong voice:
  - Not neutral resume language; reads like authored editorial copy

## Creative Direction For Satyam

Theme:
- "The Builder's Gazette" (working concept)

Tone:
- Confident, crafted, curious, experimental
- More "field notes from shipping products" than "job profile"

Visual DNA:
- Warm paper base with black ink accents and one intentional signal color
- Heavy display serif for headlines + readable serif/body + mono metadata
- Newspaper grid with strong vertical rules and modular columns

## Recommended Information Architecture

1. Front page
   - Masthead
   - Dateline (Bangalore, edition, issue number)
   - Lead story (who you are + core thesis)
   - Breaking metrics strip (years, products, users, performance wins)
2. Feature stories (selected projects)
   - 3-5 flagship stories with editorial summaries
   - "Read case file" interaction instead of generic "View project"
3. Dispatches (experience timeline)
   - Each role as a publication entry with impact headline + body
4. Public records (open source)
   - Contributions, modules, libraries, links
5. Notebook (writing)
   - Existing blog post and future short essays
6. Press desk (contact)
   - Contact CTA with personality, not plain form copy

## Copy Principles (To Avoid Boring Portfolio Voice)

- Use active verbs with outcomes:
  - "Reduced P95 load time from 10s to <1s"
  - "Shipped 50+ interactive games used in live classes"
- Lead each section with an editorial line, then support with facts
- Replace generic labels:
  - "Work" -> "Field Reports"
  - "Projects" -> "Special Features"
  - "Skills" -> "Tools of the Desk"
- Keep one strong human belief statement near the top

## Motion And Interaction Principles

- Subtle paper-like reveals (fade + slight y-shift)
- Marquee used sparingly for key headlines only
- Horizontal drag for selected features (desktop), stacked chronology on mobile
- Hover states should feel typographic and editorial (underline sweep, ink fill)

## Mobile Adaptation Rules

- Preserve editorial feel, but simplify density
- Keep masthead and dateline compact
- Convert multi-column spreads into stacked "article blocks"
- Keep tap targets large while retaining print rhythm

## Build Plan (One By One)

1. Define brand system:
   - Typography, colors, spacing scale, border/rule system
2. Build static front page layout:
   - Masthead, hero story, metrics rail, section nav
3. Map and rewrite content:
   - Resume + current portfolio into editorial voice
4. Build feature story components:
   - Project blocks with headline, dek, metadata, and CTA
5. Build timeline + open source + contact sections
6. Add interaction polish and mobile tuning
7. Final pass:
   - Content consistency, performance, accessibility

## Launch Quality Checks

- Consistent metrics across resume and website
- Dates are logically aligned (no conflicting ranges)
- High contrast and keyboard navigation preserved
- Animations respect reduced motion preferences
